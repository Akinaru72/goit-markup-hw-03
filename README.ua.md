# goit-markup-hw-03

- Створи репозиторій **goit-markup-hw-03**.
- Склонуй створений репозиторій і скопіюй у нього файли попередньої роботи.
- Додай стилі для геометрії (ширину, відступи, поля і рамки) і позиціонування контенту за допомогою **Flexbox** для сторінок макета **[домашнього завдання #3](<https://www.figma.com/file/wuEpGhwCepGCOUw7mZFRac/Web-Studio-(Version-5.0)?type=design&node-id=302815-2553&mode=design&t=HqslgV0OjDOknzIj-0>)**

- Налаштуй **GitHub Pages** і додай посилання на живу сторінку в секцію **About** GitHub-репозиторія.

---

## A — Проєкт

- **A1** — У корені проєкту є папка `images/` із зображеннями.
- **A2** — У корені проєкту є папка `css/` із файлом стилів.
- **A3** — Всі стилі написані в одному файлі `styles.css`, який знаходиться в папці `css/`.
- **A4** — У назвах файлів немає великих літер, пробілів і трансліту — тільки малі англійські літери.
- **A5** — Вихідний код відформатований за допомогою **Prettier**.
- **A6** — Всі зображення та текстовий контент взяті з макета.
- **A7** — Підключений нормалізатор стилів **[modern-normalize](https://github.com/sindresorhus/modern-normalize)**.
- **A8** — Код написаний з дотриманням рекомендацій **[Code Guide](https://codeguide.co/)**.

---

## B — Оформлення

- **B1** — Допускається глобальне скидання стилів для `h1–h6`, `p`, `ul`.
- **B2** — В елементів відсутні зовнішні відступи (`margin`), що «пробивають» батьківський елемент.
- **B3** — Вертикальні відступи між сусідніми елементами задані через `margin`.
- **B4** — Відступ між рамкою батьківського елемента і контентом заданий через `padding`.
- **B5** — Значення `margin` і `padding` точно відповідають макету.
- **B6** — Створений загальний допоміжний клас `.container` для центрування контенту.
- **B8** — Ширина контейнера відповідає макету і становить **1158px**.
- **B9** — Контейнер знаходиться всередині `header`, `footer` і всіх секцій.
- **B10** — Для розташування елементів використовується **Flexbox** лише там, де це необхідно.
- **B11** — Фінальні розміри блоків у браузері відповідають макету.
- **B12** — В елементів немає фіксованої висоти — вона визначається контентом.
- **B13** — Хедер має нижню рамку (`border-bottom`), видиму при сильному наближенні макета.
- **B14** — Секції розташовані одна під одною без зовнішніх відступів.
- **B15** — Всі секції мають клас `.section` з верхнім і нижнім `padding` по **120px**.
- **B16** — Для приховування заголовка використано патерн **visually-hidden**:

```css
.visually-hidden {
  position: absolute;
  width: 1px;
  height: 1px;
  margin: -1px;
  border: 0;
  padding: 0;
  white-space: nowrap;
  clip-path: inset(100%);
  clip: rect(0 0 0 0);
  overflow: hidden;
}
```

- **B17** — У карток секції **Our Portfolio** є рамка (`border`) лише в нижній частині картки.
